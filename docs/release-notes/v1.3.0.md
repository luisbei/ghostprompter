**RecordPlease** (formerly *Ghostprompter*) — record your lessons with a voice-following teleprompter that stays out of your video. Free, offline, for Windows.

## New name
The project is now called **RecordPlease**, to avoid confusion with an unrelated product of a similar name. Nothing else about how the app works changes:
- updating from Ghostprompter 1.2 keeps your **settings, downloaded speech models and recordings folder** — data is moved automatically from `%LOCALAPPDATA%\Ghostprompter` to `%LOCALAPPDATA%\RecordPlease` on first launch;
- if you recorded into `Videos\Ghostprompter`, new recordings keep going there (new installs use `Videos\RecordPlease`);
- the repository moved to `github.com/luisbei/recordplease` (old links redirect), and the DOI stays the same;
- the program file is now `RecordPlease.exe` (when updating, it stays in the folder you already had, usually `%LOCALAPPDATA%\Programs\Ghostprompter`). If you created a firewall rule or antivirus exception for `Ghostprompter.exe`, recreate it for `RecordPlease.exe`; taskbar pins to the old program need to be pinned again.

## Download
1. Download **`RecordPlease-Setup-1.3.0.exe`** below (*Assets*).
2. Check its fingerprint against `SHA256SUMS.txt` on this page — in PowerShell: `Get-FileHash .\RecordPlease-Setup-1.3.0.exe` (the result must match).
3. Read `LEIA-ME.txt` (Portuguese) or the [README](https://github.com/luisbei/recordplease#readme): purpose, responsible use, and what to do if Windows or your antivirus warns you.

The installer is **not digitally signed yet**, so Windows may show "Windows protected your PC". After checking where the file came from, use *More info → Run anyway*. Never create antivirus exclusions for whole folders.

## Code signing policy
This installer was built by GitHub Actions from the tagged commit of the public repository. The project has applied for free code signing for open-source projects from the [SignPath Foundation](https://signpath.org); once approved, releases will be signed through it. Details, roles and privacy statement: [CODE_SIGNING.md](https://github.com/luisbei/recordplease/blob/main/CODE_SIGNING.md).

**Not** made to cheat in interviews, exams or proctored assessments — see *Purpose and responsible use* in the README.
