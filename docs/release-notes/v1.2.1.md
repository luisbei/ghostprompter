Maintenance release of **Ghostprompter** — a free, offline teleprompter that follows your voice and records your
screen, webcam and microphone, made for **lectures and presentations**.

## Download
1. Download **`Ghostprompter-Setup-1.2.1.exe`** below (*Assets*).
2. Check its fingerprint against `SHA256SUMS.txt` on this page — in PowerShell:
   `Get-FileHash .\Ghostprompter-Setup-1.2.1.exe` (the result must match).
3. Read `LEIA-ME.txt` (Portuguese) or the [README](https://github.com/luisbei/ghostprompter#readme): purpose, responsible
   use, and what to do if Windows or your antivirus warns you.

The installer is **not digitally signed yet**, so Windows may show "Windows protected your PC". After checking where
the file came from, use *More info → Run anyway*. Never create antivirus exclusions for whole folders.

## Code signing policy
This installer was built by GitHub Actions from the tagged commit of the public repository. The project has applied
for free code signing for open-source projects from the [SignPath Foundation](https://signpath.org); once approved,
releases will be signed through it. Details, roles and privacy statement:
[CODE_SIGNING.md](https://github.com/luisbei/ghostprompter/blob/main/CODE_SIGNING.md).

## What's new
- Installer: the license/notice screen now reflows its text to the window width (no more lines broken mid-sentence).
- Documentation in English first, with Portuguese and Spanish: README, privacy policy and third-party notices.
- README screenshots and a demo of "Follow my voice"; English example script; security policy
  ([SECURITY.md](https://github.com/luisbei/ghostprompter/blob/main/SECURITY.md)).
- Citation metadata ready for a DOI via Zenodo ([CITATION.cff](https://github.com/luisbei/ghostprompter/blob/main/CITATION.cff)).

The app itself works exactly like 1.2.0. Your settings and speech models are kept when updating.

**Not** made to cheat in interviews, exams or proctored assessments — see *Purpose and responsible use* in the README.
